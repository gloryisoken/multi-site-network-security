# multi-site-network-security
Cisco Packet Tracer project implementing and testing security controls across a simulated three-site enterprise network.
Module: Network Security
Institution: Technological University Dublin
Tools: Cisco Packet Tracer

# Project Overview
This academic project involved implementing and testing network security controls across a simulated three-site enterprise network consisting of Dublin headquarters, a London data centre and a Beijing home office.
The objective was to strengthen network security through device hardening, authentication, access controls, monitoring and secure network configurations.

# Security Controls Implemented
Device Hardening: Configured secure administrative access using SSHv2, password controls and session timeouts.
AAA Authentication: Implemented RADIUS authentication with local fallback.
Routing Security: Configured OSPF message-digest authentication.
Access Control: Applied extended ACLs to restrict communication between departmental VLANs.
Monitoring: Configured Syslog and NTP services.
LAN and Wireless Security: Applied switch port security and WPA2-AES wireless protection.
Network Address Translation: Configured and tested PAT.

# Testing and Troubleshooting
I verified security configurations through connectivity tests, ACL match counters, routing-neighbour checks and wireless connectivity testing.
Troubleshooting included resolving OSPF authentication mismatches and reconnecting wireless clients after security configuration changes.

# Project Limitations
Some requirements were not fully implemented, including the site-to-site VPN, static NAT configuration and complete firewall policy. These limitations are documented in the technical report.
